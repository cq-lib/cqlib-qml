cqlib_qml.differentiator

Gradient computation methods for parameterized quantum circuits.

This module provides different differentiation methods for computing gradients of parameterized quantum circuits. The gradients are essential for training variational quantum algorithms and quantum neural networks.

Available Differentiators: - AdjointDifferentiator: Uses the adjoint method for efficient gradient computation. Suitable for classical simulation. - ParameterShiftDifferentiator: Uses the parameter shift rule for gradient computation. More suitable for hardware execution.

The choice of differentiator affects both computational efficiency and accuracy. The adjoint method is generally faster for simulation, while the parameter shift method is more hardware-compatible.

References: - Parameter Shift Rule: Mitarai et al. (2018). "Quantum circuit learning" - Adjoint Method: Jones (2020). "Efficient quantum gradient computation"

Examples:

from cqlib_qml.differentiator import AdjointDifferentiator, ParameterShiftDifferentiator from cqlib.circuit import Circuit, Parameter

Create a parameterized circuit

circuit = Circuit(1) theta = Parameter("theta") circuit.ry(0, theta)

Adjoint differentiator (faster for simulation)

adjoint = AdjointDifferentiator() grads = adjoint.run(circuit, {"theta": 0.5}, readouts=[0])

Parameter shift differentiator (hardware-friendly)

ps = ParameterShiftDifferentiator(shift=np.pi/2) grads = ps.run(circuit, {"theta": 0.5}, readouts=[0])

 94        Calculate gradients of a parameterized quantum circuit.
 95
 96        This method computes the gradients of all parameters in the circuit
 97        with respect to the expectation value of the given observables
 98        (readouts or Hamiltonians).
 99
100        Args:
101            circuit (Circuit): Parameterized quantum circuit.
102                Must contain at least one parameter.
103            bindings (Dict[Union[str, Parameter], float]): Parameter
104                bindings mapping parameter names/objects to values.
105            state_vector (np.ndarray, optional): State vector from the
106                forward pass. Required for adjoint method.
107                Defaults to None.
108            readouts (List[int], optional): Qubit indices for Pauli-Z
109                measurements. Either readouts or hamiltonians must be
110                provided. Defaults to None.
111            hamiltonians (List[Hamiltonian], optional): Observables for
112                expectation computation. Either readouts or hamiltonians
113                must be provided. Defaults to None.
114
115        Returns:
116            Dict[str, np.ndarray]: Dictionary mapping parameter names
117                to gradient values.
118
119        Raises:
120            ValueError: If circuit has no parameters or parameters are
121                not properly assigned.
122            TypeError: If hamiltonians or readouts have invalid types.
123
124        Examples:
125            >>> # Using readouts
126            >>> grads = diff.run(circuit, {"theta": 0.5},
127            ...                  state_vector=state_vector,
128            ...                  readouts=[0])
129            >>>
130            >>> # Using Hamiltonians
131            >>> grads = diff.run(circuit, {"theta": 0.5},
132            ...                  state_vector=state_vector,
133            ...                  hamiltonians=[ham])
134        """
135        circuit = circuit.decompose()
136        if len(circuit.parameters) == 0:
137            raise ValueError("The input circuit must be a parameterized quantum circuit.")
138        if set(circuit.symbols) != set(bindings.keys()):
139            raise ValueError("All parameters in the circuit must be assigned.")
140        try:
141            assigned_cir = circuit.assign_parameters(bindings)
142        except:
143            raise ValueError("Cannot assign values to the current circuit.")
144
145        if readouts is not None:
146            readouts = self._check_readouts(readouts, circuit.num_qubits)
147            hamiltonians = []
148            for readout in readouts:
149                ham = Hamiltonian(circuit.num_qubits)
150                pauli = "".join(
151                    ["Z" if i == circuit.num_qubits - 1 - readout else "I" for i in range(circuit.num_qubits)]
152                )
153                ham.add_term(PauliString.from_str(pauli), 1)
154                hamiltonians.append(ham)
155        hamiltonians = self._check_hamiltonians(hamiltonians)
156
157        n_qubits, pipeline, free_symbols, training_gates = self._initial_circuit(circuit, assigned_cir)
158
159        gradients = dict()
160        for hamiltonian in hamiltonians:
161            state = state_vector if len(hamiltonians) == 1 else state_vector.copy()
162            grads_dict = self._run(state, n_qubits, pipeline, free_symbols, training_gates, hamiltonian, bindings)
163            if len(gradients) == 0:
164                gradients = grads_dict.copy()
165            else:
166                for key in grads_dict.keys():
167                    gradients[key] = np.append(gradients[key], grads_dict[key])

171    def _run(
172        self,
173        state: np.ndarray,
174        n_qubits: int,
175        pipeline: dict,
176        free_symbols: tuple,
177        training_gates: int,
178        hamiltonian: Hamiltonian,
179        bindings: dict,
180    ) -> Dict[str, np.ndarray]:
181        """
182        Internal method for running the adjoint gradient computation.
183
184        Args:
185            state (np.ndarray): Initial state vector.
186            n_qubits (int): Number of qubits.
187            pipeline (dict): Parsed circuit pipeline.
188            free_symbols (tuple): Symbolic parameters.
189            training_gates (int): Number of trainable gates.
190            hamiltonian (Hamiltonian): Observable Hamiltonian.
191            bindings (dict): Parameter bindings.
192
193        Returns:
194            Dict[str, np.ndarray]: Gradient dictionary.
195        """
196        grads_dict = dict()
197        remain_training_gates = training_gates
198        vector = Statevector.from_state(n_qubits, state)
199        for symbol in free_symbols:
200            grads_dict[symbol] = np.array([0], dtype=np.double)
201
202        # Calculate d(L)/d(|psi_t>)
203        grad = self._initial_grad_vector(state, n_qubits, hamiltonian)
204        grad_vector = self._norm_grad_vector(n_qubits, grad)
205
206        for idx in range(len(pipeline["qubits"])):
207            if remain_training_gates == 0:
208                return grads_dict
209            # Calculate |psi_t-1>
210            inv_op = pipeline["inv_op"][idx]
211            qubits = pipeline["qubits"][idx]
212            self._apply_gate(inv_op, qubits, vector)
213
214            # Calculate d(L)/d(theta) and write to grads_dict
215            params = pipeline["params"][idx]
216            if any(isinstance(param, Parameter) for param in params):
217                remain_training_gates -= 1
218                grad_matrix = pipeline["grad_matrix"][idx]
219                grads_dict = self._calculate_grad(
220                    grads_dict, qubits, grad_matrix, params, vector, grad_vector, bindings
221                )
222
223            # Calculate d(L)/d(|psi_t-1>)
224            self._apply_gate(inv_op, qubits, grad_vector)
225
226        return grads_dict

228    def _norm_grad_vector(self, n_qubits: int, grad: np.ndarray) -> Statevector:
229        """
230        Normalize the gradient vector.
231
232        Args:
233            n_qubits (int): Number of qubits.
234            grad (np.ndarray): Unnormalized gradient vector.
235
236        Returns:
237            Statevector: Normalized gradient vector as a quantum state.
238        """
239        self._grad_norm = np.linalg.norm(grad)
240        if self._grad_norm < 1e-12:
241            return Statevector(n_qubits)
242
243        grad_normalized = grad / self._grad_norm
244        try:
245            grad_vector = Statevector.from_state(n_qubits, grad_normalized)
246        except ValueError as e:
247            if "not normalized" in str(e):
248                current_norm = np.linalg.norm(grad_normalized)
249                if abs(current_norm - 1.0) > 1e-8:
250                    grad_normalized = grad_normalized / current_norm
251                grad_vector = Statevector.from_state(n_qubits, grad_normalized)
252            else:
253                raise ValueError
254
255        return grad_vector

324    def _parse_circuits(self, circuit: Circuit, assigned_cir: Circuit) -> tuple:
325        """
326        Parse circuits for gradient computation.
327
328        Args:
329            circuit (Circuit): Original circuit.
330            assigned_cir (Circuit): Circuit with assigned parameters.
331
332        Returns:
333            tuple: (pipeline, training_gates)
334        """
335        pipeline = {"qubits": [], "grad_matrix": [], "training_gate": [], "params": [], "inv_op": []}
336        training_gates = 0
337        inv_circuit = assigned_cir.inverse()
338        for op, origion_op, inv_op in zip(
339            list(assigned_cir.operations)[::-1], list(circuit.operations)[::-1], inv_circuit.operations
340        ):
341            if op.instruction.instruction_type in ["circuit", "directive"]:
342                continue
343            pipeline["qubits"].append([qubit.index for qubit in op.qubits])
344            pipeline["grad_matrix"].append(op.grad_matrix())
345            params = []
346            is_training_gate = False
347            for param in origion_op.params:
348                if isinstance(param, tuple):
349                    param_name = circuit.parameters[param[1]]
350                    params.append(param_name)
351                    is_training_gate = True
352                else:
353                    params.append(param)
354            if is_training_gate:
355                training_gates += 1
356            pipeline["training_gate"].append(is_training_gate)
357            pipeline["params"].append(params)
358            pipeline["inv_op"].append(inv_op)
359
360        return pipeline, training_gates

362    def _construct_hamilton_circuit(self, n_qubits: int, hamiltonian: Hamiltonian) -> tuple:
363        """
364        Construct circuit for Hamiltonian expectation.
365
366        Args:
367            n_qubits (int): Number of qubits.
368            hamiltonian (Hamiltonian): Hamiltonian observable.
369
370        Returns:
371            tuple: (coefficients, circuit_list)
372        """
373        hamiltonian.simplify()
374        coefficients = []
375        circuit_list = []
376        for pauli_str, coeff in hamiltonian.terms:
377            coefficients.append(coeff)
378            circuit = Circuit(n_qubits)
379            for idx in range(pauli_str.num_qubits):
380                if pauli_str.get_pauli(idx) == Pauli.x():
381                    circuit.x(idx)
382                if pauli_str.get_pauli(idx) == Pauli.y():
383                    circuit.y(idx)
384                if pauli_str.get_pauli(idx) == Pauli.z():
385                    circuit.z(idx)
386            circuit_list.append(circuit)
387
388        return coefficients, circuit_list

390    def _initial_grad_vector(self, state_vector: np.ndarray, n_qubits: int, expectation_op: Hamiltonian) -> np.ndarray:
391        """
392        Compute initial gradient vector.
393
394        Args:
395            state_vector (np.ndarray): State vector.
396            n_qubits (int): Number of qubits.
397            expectation_op (Hamiltonian): Observable Hamiltonian.
398
399        Returns:
400            np.ndarray: Initial gradient vector.
401        """
402        coefficients, circuit_list = self._construct_hamilton_circuit(n_qubits, expectation_op)
403        grad_vector = np.zeros(1 << n_qubits, dtype=np.complex128)
404        for coeff, circuit in zip(coefficients, circuit_list):
405            sv = Statevector(n_qubits)
406            sv = sv.from_state(n_qubits, state_vector)
407            sv.apply_circuit(circuit)
408            grad_vector += coeff * sv.data
409
410        return grad_vector

412    def _apply_gate(self, op, qubits: List[int], vector: Statevector) -> None:
413        """
414        Apply a gate operation to a state vector.
415
416        Args:
417            op: Gate operation.
418            qubits (List[int]): Qubit indices.
419            vector (Statevector): State vector to modify.
420
421        Raises:
422            ValueError: If operation type is unsupported.
423        """
424        if op.instruction.standard_gate:
425            inv_gate = op.instruction.standard_gate
426            vector.apply_standard_gate(inv_gate, qubits, op.params)
427        elif op.instruction.mc_gate or op.instruction.unitary_gate:
428            vector.apply_unitary_gate(qubits, op.matrix())
429        else:
430            raise ValueError(f"Unsupported operation type: {op.instruction.instruction_type}")

432    def _calculate_grad(
433        self,
434        grads_dict: dict,
435        qubits: List[int],
436        grad_matrix: np.ndarray,
437        params: List,
438        vector: Statevector,
439        grad_vector: Statevector,
440        bindings: dict,
441    ) -> dict:
442        """
443        Calculate gradient for a specific parameter.
444
445        Args:
446            grads_dict (dict): Accumulated gradients.
447            qubits (List[int]): Qubit indices.
448            grad_matrix (np.ndarray): Gradient matrix.
449            params (List): Parameter list.
450            vector (Statevector): Current state vector.
451            grad_vector (Statevector): Gradient vector.
452            bindings (dict): Parameter bindings.
453
454        Returns:
455            dict: Updated gradients dictionary.
456        """
457        for i in range(len(params)):
458            if isinstance(params[i], Parameter):
459                state = vector.copy()
460                # d(|psi_t>) / d(theta_t^j)
461                if len(qubits) == 1:
462                    state.apply_single_qubit_gate(qubits[0], grad_matrix[i])
463                elif len(qubits) == 2:
464                    state.apply_double_qubits_gate(qubits[0], qubits[1], grad_matrix[i])
465                else:
466                    state.apply_unitary_gate(qubits, grad_matrix[i])
467
468                # d(L)/d(theta_t^j) = d(L)/d(|psi_t>) * d(|psi_t>)/d(theta_t^j)
469                grad = self._grad_norm * ((2.0 * grad_vector.data) @ state.data.conj()).real
470
471                # write gradient
472                for symbol in params[i].symbols:
473                    derivative = params[i].derivative(symbol)
474                    grads_dict[symbol] += (float(grad) * derivative.evaluate(bindings)).real
475
476        return grads_dict

 45class ParameterShiftDifferentiator:
 46    """
 47    Parameter shift differentiator for quantum circuits.
 48
 49    Computes gradients using the parameter shift rule:
 50    ∂f/∂θ = (f(θ + s) - f(θ - s)) / (2 * sin(s))
 51
 52    where s is the shift amount (default π/2). This rule applies to
 53    gates of the form exp(-i θ G / 2) where G² = I.
 54
 55    This method is hardware-friendly as it requires only circuit
 56    evaluations, making it suitable for running on quantum devices.
 57
 58    Args:
 59        shift: The shift amount in radians. Default is π/2.
 60            Valid shifts are those where sin(shift) ≠ 0.

170    def _run(
171        self, circuit: Circuit, bindings: Dict[Union[str, Parameter], float], hamiltonians: List[Hamiltonian]
172    ) -> Dict[str, np.ndarray]:
173        """
174        Internal method for parameter shift gradient computation.
175
176        Args:
177            circuit (Circuit): Parameterized quantum circuit.
178            bindings (Dict): Parameter bindings.
179            hamiltonians (List[Hamiltonian]): Observables.
180
181        Returns:
182            Dict[str, np.ndarray]: Gradient dictionary.
183        """
184        gradients = dict()
185        base_vals = [bindings[symbol] for symbol in circuit.symbols]
186        for i in range(len(circuit.symbols)):
187            # Evaluate at θ + shift
188            pos_vals = base_vals.copy()
189            pos_vals[i] += self._shift
190            pos_exps = self._compute_expectations(circuit, pos_vals, hamiltonians)
191            # Evaluate at θ - shift
192            neg_vals = base_vals.copy()
193            neg_vals[i] -= self._shift
194            neg_exps = self._compute_expectations(circuit, neg_vals, hamiltonians)
195            # Apply parameter shift rule
196            gradients[circuit.symbols[i]] = (pos_exps - neg_exps) / (2.0 * np.sin(self._shift))
197
198        return gradients

200    def _compute_expectations(
201        self, circuit: Circuit, parameters: np.ndarray, hamiltonians: List[Hamiltonian]
202    ) -> np.ndarray:
203        """
204        Compute expectation values for all Hamiltonians.
205
206        Args:
207            circuit (Circuit): Quantum circuit.
208            parameters (np.ndarray): Parameter values.
209            hamiltonians (List[Hamiltonian]): Observables.
210
211        Returns:
212            np.ndarray: Array of expectation values.
213        """
214        n_qubits = circuit.num_qubits
215        bindings = dict(zip(circuit.symbols, parameters))
216        assigned_cir = circuit.assign_parameters(bindings)
217        state = Statevector(n_qubits)
218        state.apply_circuit(assigned_cir)
219        expectations = []
220        for ham in hamiltonians:
221            expectation = ham.expectation_statevector(state)
222            expectations.append(expectation)
223
224        return np.array(expectations)

227        """
228        Validate and format Hamiltonians.
229
230        Args:
231            hams: Hamiltonian or list of Hamiltonians.

233        Returns:
234            List[Hamiltonian]: List of validated Hamiltonians.

236        Raises:
237            TypeError: If input has invalid type.
238        """
239        if isinstance(hams, Hamiltonian):
240            hams = [hams]
241        if isinstance(hams, list):
242            for i in range(len(hams)):
243                hams[i].simplify()
244                if not isinstance(hams[i], Hamiltonian):
245                    raise TypeError(f"Expected Hamiltonian, got {type(hams[i]).__name__}")
246        else:
247            raise TypeError(f"Expected Hamiltonian or List[Hamiltonian], got {type(hams).__name__}")
248        return hams

Parameter shift differentiator for quantum circuits.

Computes gradients using the parameter shift rule: ∂f/∂θ = (f(θ + s) - f(θ - s)) / (2 * sin(s))

where s is the shift amount (default π/2). This rule applies to gates of the form exp(-i θ G / 2) where G² = I.

This method is hardware-friendly as it requires only circuit evaluations, making it suitable for running on quantum devices.

Args: shift: The shift amount in radians. Default is π/2. Valid shifts are those where sin(shift) ≠ 0.

Attributes: _shift (float): The shift amount used for gradient computation.

Raises: ValueError: If shift results in sin(shift) = 0.

References: - Mitarai, K. et al. (2018). "Quantum circuit learning" - Schuld, M. et al. (2019). "Evaluating analytic gradients on quantum hardware"
