# 接口迁移说明

## 门矩阵导数

导入 `cqlib_qml` 不再向 cqlib 的 `ValueOperation` 类注入方法。曾依赖注入接口的外部代码需要迁移：

```python
# 旧调用（不再提供）
# derivative = op.grad_matrix()

from cqlib_qml.utils import grad_matrix
derivative = grad_matrix(op)
```

这是明确的接口兼容变化；项目内部调用已迁移为辅助函数。辅助函数的返回结构与原注入方法一致。

## 训练配置与状态

VQC 的 `epochs` 只接受正整数，`batch_size` 只接受正整数或 `None`；零、负数、布尔值和浮点数均报 `ValueError`。此前 `batch_size=0` 被解释为整批，现在请使用 `None`。非法配置在训练状态改变前被拒绝。

VQC 在私有副本上执行编码和训练，成功后才发布结果。编码或训练中途失败会保留上一次成功训练的模型、类别、参数与优化器状态；首次训练失败的对象仍未拟合。

加载 checkpoint 或调用 `load_params()` 会清除旧梯度、Jacobian 和反向缓存。恢复后必须重新进行训练前向和反向，才能更新参数；直接更新不会推进优化器。

QNN/HQNN 的 `freeze()` 持续生效，普通前向不再自动解除冻结。`forward(..., trainable=False)` 在校验输入前清除整个模型的旧梯度和反向缓存，即使输入无效、调用抛异常也一样；恢复训练需重新执行训练前向与反向。推理后的 `update()` 不推进优化器，也不修改参数。

优化器和调度器字符串配置拒绝未知参数，避免拼写错误被静默忽略。QSVM 的 `fit()` 支持 `sample_weight`，不接受其他训练关键字。

VQC 在构造、`set_params()` 和 `fit()` 时统一校验损失配置；只接受 `MSE`、`BCE`、`CrossEntropy`。非法 `set_params()` 不改变已有配置或拟合状态。

## 数值、输入与对象所有权

两种微分器不再隐式简化调用者的 Hamiltonian，保留小系数、重复项与 Pauli 相位。伴随态按缩放后的范数归一化；非零的小向量不再被替换成其他方向，真正为零的伴随态返回零梯度。

振幅编码与伴随法分别缩放复数向量的实部、虚部，避免次正规数（例如 `1e-310`）作为除数时产生非有限值。振幅编码的递归子向量范数也采用缩放计算。真实范数超出浮点范围的伴随态仍明确报错；低于浮点可表示范围的结果无法保证保留。

FRQI 的普通与 QIC 编码仅跳过精确零像素，不再在归一化前按 `1e-12` 剪枝。因此很小的正数图像仍遵循按图像最大值归一化的定义；全零图像单独保留无颜色旋转的状态。

QSVM 保存训练特征的内部副本，修改传入的原始数组不影响已拟合模型的预测。QKM 接受一维单样本或二维非空数值批次，支持振幅编码的复数输入；非法输入抛 `ValueError`。编码或模拟失败不会提交新的特征维度、量子位数或线路缓存。
