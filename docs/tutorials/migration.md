# 接口迁移说明

## 门矩阵导数

导入 `cqlib_qml` 不再向 cqlib 的 `ValueOperation` 类注入方法。曾依赖注入接口的外部代码需要迁移：

```python
# 旧调用（不再提供）
# derivative = op.grad_matrix()

from cqlib_qml.utils import grad_matrix
derivative = grad_matrix(op)
```

这是明确的接口兼容变化；项目内部调用已迁移为辅助函数。辅助函数的返回结构与原注入方法一致。

## 训练配置与状态

VQC 的 `epochs` 只接受正整数，`batch_size` 只接受正整数或 `None`；零、负数、布尔值和浮点数均报 `ValueError`。此前 `batch_size=0` 被解释为整批，现在请使用 `None`。非法配置在训练状态改变前被拒绝。

VQC 在私有副本上执行编码和训练，成功后才发布结果。编码或训练中途失败会保留上一次成功训练的模型、类别、参数与优化器状态；首次训练失败的对象仍未拟合。

加载 checkpoint 或调用 `load_params()` 会清除旧梯度、Jacobian 和反向缓存。恢复后必须重新进行训练前向和反向，才能更新参数；直接更新不会推进优化器。

QNN/HQNN 的 `freeze()` 持续生效，普通前向不再自动解除冻结。`forward(..., trainable=False)` 在校验输入前清除整个模型的旧梯度和反向缓存，即使输入无效、调用抛异常也一样；恢复训练需重新执行训练前向与反向。推理后的 `update()` 不推进优化器，也不修改参数。

优化器和调度器字符串配置拒绝未知参数，避免拼写错误被静默忽略。QSVM 的 `fit()` 支持 `sample_weight`，不接受其他训练关键字。

VQC 在构造、`set_params()` 和 `fit()` 时统一校验损失配置；只接受 `MSE`、`BCE`、`CrossEntropy`。非法 `set_params()` 不改变已有配置或拟合状态。QNN/HQNN 训练示例现在将当前损失传给优化器，支持 KingScheduler。

## 数值、输入与对象所有权

两种微分器不再隐式简化调用者的 Hamiltonian，保留小系数、重复项与 Pauli 相位。伴随态按缩放后的范数归一化；非零的小向量不再被替换成其他方向，真正为零的伴随态返回零梯度。

振幅编码与伴随法分别缩放复数向量的实部、虚部，避免次正规数（例如 `1e-310`）作为除数时产生非有限值。振幅编码的递归子向量范数也采用缩放计算。真实范数超出浮点范围的伴随态仍明确报错；低于浮点可表示范围的结果无法保证保留。

FRQI 的普通与 QIC 编码仅跳过精确零像素，不再在归一化前按 `1e-12` 剪枝。因此很小的正数图像仍遵循按图像最大值归一化的定义；全零图像单独保留无颜色旋转的状态。

QSVM 保存训练特征的内部副本，修改传入的原始数组不影响已拟合模型的预测。QKM 接受一维单样本或二维非空数值批次，支持振幅编码的复数输入；非法输入抛 `ValueError`。编码或模拟失败不会提交新的特征维度、量子位数或线路缓存。

DataLoader 的 `batch_size` 必须是正整数，接受 NumPy 整数，拒绝布尔值、浮点数、零和负数，构造时即校验。FRQI/NEQR 的单像素 QIC 编码使用无位置控制的颜色门。

## 回归测试如何避免重复漏检

以行为契约组织测试，而不是仅按函数组织：数值结果与尺度、调用者对象是否被修改、失败后状态是否保留、重复调用是否一致，以及组件组合是否能执行。微小梯度不能使用会掩盖零结果的宽松绝对容差。

本轮缺陷分别来自近零向量方向替换、隐式剪枝、数组别名、配置入口校验不一致、状态过早提交、缺少调度器损失传递、零位置量子位分支缺失及批大小未校验。此前主路径和类型/形状检查不足以发现这些问题。新增测试先在旧实现上复现失败，再验证修复；部分测试同时保护原本正确的行为，不要求每个测试都先失败。

测试通过说明已验证的契约成立，不代表穷尽全部数值、依赖版本和平台组合。后续审查应区分遗留缺陷、新引入的回归和明确的使用限制。

后续每轮修复应检查：整体及子分支的数值尺度、缩放不变性、成功与失败调用后的训练状态、冻结与恢复训练，以及组件组合。此次遗漏来自整体归一化测试未覆盖次正规数与递归子分支，成功推理测试未覆盖入口校验失败。发现新问题不等于每次修复都引入新问题，但也不能只修复单个复现输入而不检查相邻契约。

## 当前验证范围与后续工作

Ruff 配置只覆盖 `E9/F63/F7/F82` 错误检查，通过不代表完成全量 E/F 清理或统一格式化。跨平台 CI 矩阵需以实际运行结果确认；配置文件本身不构成兼容性验证。

QKM 的重复状态模拟与对称核计算优化仍未实施。它们属于后续性能工作。

本轮还复现了 cqlib 2.0.0b3 的极端参数表达式限制：`(Parameter('t') / 1e200).derivative('t')` 求值得到 `0.0`，数学结果应为 `1e-200`。QML 的表达式链式求导依赖该接口；本轮没有修改 cqlib，也不保证任意极端参数尺度都可正确求导。伴随态尺度测试单独验证观测量缩放，避免把底层表达式问题与向量归一化问题混为一谈。

当前 cqlib 模拟直接执行 `RY(2e-150)` 时也可能丢失对应极小振幅。QML 的递归编码测试因此独立检查生成的门角度（例如 `[1, 1e-170]` 对应约 `2e-170`），不将底层模拟结果误认为线路生成正确性的唯一证据。这项底层限制没有在本轮修复。
