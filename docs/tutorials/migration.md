# 接口迁移说明

## 门矩阵导数

导入 `cqlib_qml` 不再向 cqlib 的 `ValueOperation` 类注入方法。曾依赖注入接口的外部代码需要迁移：

```python
# 旧调用（不再提供）
# derivative = op.grad_matrix()

from cqlib_qml.utils import grad_matrix
derivative = grad_matrix(op)
```

这是明确的接口兼容变化；项目内部调用已迁移为辅助函数。辅助函数的返回结构与原注入方法一致。

## 数值、输入与对象所有权

两种微分器不再隐式简化调用者的 Hamiltonian，保留小系数、重复项与 Pauli 相位。伴随态按缩放后的范数归一化；非零的小向量不再被替换成其他方向，真正为零的伴随态返回零梯度。

振幅编码与伴随法分别缩放复数向量的实部、虚部，避免次正规数（例如 `1e-310`）作为除数时产生非有限值。振幅编码的递归子向量范数也采用缩放计算。真实范数超出浮点范围的伴随态仍明确报错；低于浮点可表示范围的结果无法保证保留。

FRQI 的普通与 QIC 编码仅跳过精确零像素，不再在归一化前按 `1e-12` 剪枝。因此很小的正数图像仍遵循按图像最大值归一化的定义；全零图像单独保留无颜色旋转的状态。
