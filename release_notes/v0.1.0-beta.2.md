# Cqlib-QML v0.1.0-beta.2

Beta 2 adds reproducible initialization, explicit input and weight parameter roles, gradient accumulation, and resumable training. It also defines how VQC retraining and warm starts behave, with regression fixes for checkpoint loading, data shuffling, and model reinitialization.

These notes cover changes since `v0.1.0-beta.1`.

## New Features

### Reproducible Initialization and Shuffling

- Added `random_state` support to `Ansatz`, `Linear`, `Module`, `QNN`, `HQNN`, `VQC`, and `DataLoader`.
- Components own their NumPy generators. Passing a generator copies its state without consuming the caller's generator or changing global NumPy randomness.
- Use an integer seed to reproduce initialization and shuffled batch order.

### Input and Weight Parameter Roles

- Added `Ansatz.set_parameter_roles(input_params=..., weight_params=...)` to distinguish per-sample inputs from shared trainable weights in the same circuit.
- Added `assign_weights`, `weights`, `num_inputs`, and `num_weights` for explicit weight management.
- Added `input_jacobian`, `weight_jacobian`, and `weight_gradients`. `backward()` returns input gradients and accumulates shared weight gradients.
- Both adjoint and parameter-shift differentiation support the same input and weight gradient behavior.

### Gradient Accumulation and Execution Modes

- Quantum components and `Linear` accumulate parameter gradients across backward calls, supporting microbatch training with caller-supplied loss scaling.
- `zero_grad()` clears accumulated gradients while preserving the latest recorded forward cache.
- Frozen components continue to propagate input gradients, allowing preceding classical layers to train.
- Added `train()` and `eval()` modes independent of freezing and gradient recording. Disabling recording preserves pending parameter gradients and invalidates the backward cache.

### VQC Retraining, Warm Starts, and Resume

- Added `initial_point` and `warm_start`; construction objects remain templates, and learned components are exposed through `ansatz_` and `encoder_`.
- Default repeated `fit()` starts from the declared initialization and resets optimizer and scheduler history.
- `warm_start=True` retains learned weights and the current random stream, while resetting optimizer and scheduler history.
- Added `fit(..., max_steps=k)` to pause after complete mini-batch updates, and `resume_fit(..., max_steps=k, additional_epochs=n)` to continue training with its saved optimizer, scheduler, random state, and progress.
- Added `reset_state()` hooks for optimizers and schedulers, including custom implementations used by VQC training.

### Versioned Checkpoints

- Introduced checkpoint `format_version=1`, saving model structure, parameter roles, weights, freeze and execution modes, differentiation configuration, optimizer and scheduler state, and random generator state.
- Added VQC checkpoint saving and loading, including class mapping, training progress, shuffled order, next-batch position, and data identity checks for exact resume.
- Added `DataLoader.state_dict()` and `load_state_dict()`. Module checkpoints can include loader state through `data_loader=loader`; QNN and HQNN classification helpers resume the saved batch order and position.
- Loading validates candidate state before replacing live state. Checkpoint writes use temporary files and atomic replacement.
- Training checkpoints require cleared gradients after a complete update. Run `zero_grad()` before saving; backward caches are rebuilt with a new forward pass after loading.

## Fixes

- Fixed VQC checkpoint loading when the original Ansatz template and the trained VQC use different numbers of readouts. The template and learned model now retain their respective measurement configurations.
- Fixed DataLoader restoration before its first iteration: the restored loader performs the same initial shuffle as the original. An already-created permutation is preserved when no batch has yet been consumed.
- Fixed `Module.random_init()` retaining stale quantum gradients. Reinitialization now clears accumulated gradients and forward caches, so an update without a new backward pass leaves the new weights unchanged.

## Migration from Beta 1

This release changes several training APIs and checkpoint behavior:

- **Randomness:** use `random_state` instead of relying on global `np.random.seed()` to control model initialization or loader shuffling.
- **VQC learned state:** read trained weights from `vqc.ansatz_`; `vqc.ansatz` remains the construction template. Use `warm_start=True` to retain weights on another fit, or `resume_fit()` to retain the complete training state.
- **Backward results:** `Ansatz.backward()` returns input gradients with shape `(batch, inputs)`. Read parameter gradients through `gradients` or `weight_gradients`, and query Jacobians through `jacobian`, `input_jacobian`, or `weight_jacobian`. With no upstream gradient, backward differentiates the sum of outputs.
- **Single samples:** `Linear` and `Module` input gradients retain the batch dimension, changing from `(inputs,)` to `(1, inputs)`.
- **Gradient lifecycle:** repeated backward calls accumulate gradients. Parameter updates preserve those gradients; call `zero_grad()` after an update before starting the next ordinary training step or saving a checkpoint.
- **Old checkpoints:** unversioned beta 1 checkpoints are rejected by the new loaders; no automatic migration is provided.

For examples and the complete training behavior, see the [training contracts tutorial](https://github.com/cq-lib/cqlib-qml/blob/v0.1.0-beta.2/docs/tutorials/training_contracts.md).

## Documentation and Validation

- Updated tutorials for parameter roles, gradient shapes, freezing, random seeds, VQC retraining, and checkpoint resume.
- Included release notes and the training contracts tutorial in source distributions, with additional source-package content checks.
- Expanded regression coverage for gradients, state restoration, initialization, and loader progress. Local validation passed all **814 tests** on macOS with Python 3.14 and cqlib 2.0.0b3; Ruff checks also passed.

## Installation

Requirements remain **Python 3.11 or later** and **cqlib 2.0.0b3 or later**.

Once published on PyPI, install this beta version with:

```bash
python -m pip install "cqlib-qml==0.1.0b2"
```

The release tag is `v0.1.0-beta.2`; the package version `0.1.0-beta.2` is normalized to `0.1.0b2` under PEP 440.

## Beta Status and Known Limitations

- APIs and checkpoint formats may change in subsequent beta releases.
- Exact training resume requires the same training data and order, classes, batching, loss, and readouts. Checkpoints do not support saving midway through backward or microbatch gradient accumulation.
- Built-in VQC checkpoints support Angle, Amplitude, and ZZFeature encoders. Custom optimizer and scheduler checkpoint reconstruction requires a custom serialization and restoration path.
- Differentiation still uses statevector simulation. Hardware training executors, shots, and measurement statistics interfaces are not yet available.
- The cqlib 2.0.0b3 parameter-expression differentiation limitation at extreme parameter scales remains.
